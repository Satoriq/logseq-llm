# logseq-llm

AI chat panel for Logseq DB (desktop, macOS). Personal project.

- Plugin: the floating panel inside Logseq.
- Bridge: a local Node process (built-ins only) that talks to the models and runs graph tools through the `logseq` CLI. It applies privacy filtering, and every write needs approval.

Status: planning. See [docs/PLAN.md](docs/PLAN.md).
